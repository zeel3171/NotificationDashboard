# Notification Dashboard

Simple Angular dashboard to view and manage notifications.

## Features

- Filter notifications by year & month
- View read / unread summary
- Search by employee name
- Select multiple records and mark as Read / Unread
- Responsive layout for mobile & desktop

## Components

- **Dashboard**: The main view displaying the notification table, search capabilities, and bulk actions.
- **Month Tabs**: A navigation bar to filter notification history by specific months and years.
- **Summary Tabs**: Displays high-level insights summary.
- **Layouts**: Modular `Header`, `Sidebar`, and `Footer` components that build the application.

## Challenges

- Handling and Importing JSON data.
- Adjusting layout for smaller screens
